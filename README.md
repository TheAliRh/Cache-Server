# Caching Server
## Description
An Integration of Python & Redis for Caching.
Let's think that you have a web server, and every time you get a request you are using your resources to process it.
As the number of requests increases there is more pressure on your server.
One thing you colud do in this situation is implementing a caching system to reduce the pressure.
This repository is about that. 
> [!NOTE]
> This project is under development!

## Install & Run
* Clone the repository.
```
git clone https://github.com/TheAliRh/Cache-Server.git
```
* Go to the repository's directory.
``` 
cd Cache-Server
```
* Run the app.
```
python3 app.main.py 
```
